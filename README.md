# 电信行业格式条款合规观察 (Telecom Contract Compliance)

欢迎来到本项目。本项目旨在通过开源协作的方式，收集、整理并分享关于**基础电信运营商（中国电信、中国移动、中国联通、中国广电等）《入网协议》中涉嫌“不公平格式条款”的官方司法判例、国家部委规章及权威媒体报道**。

## 📌 项目背景

在现实生活中，广大消费者在与电信运营商签订服务协议时，往往面临诸如：
*   **违约金畸高**（如每日千分之三，年化超100%）
*   **单方变更/终止权**（运营商以“技术进步”等名义单方面修改合同）
*   **排他性管辖条款**（限定发生争议只能去运营商所在地法院起诉，增加消费者维权成本）
*   **个人信息“一揽子”授权**（未经单独同意，捆绑授权共享个人信息）

由于信息差和法律知识壁垒，普通消费者在面对这些格式条款时往往处于弱势。本项目汇总了全国各地法院的生效判例和国家监管部门的定调，**旨在为消费者、公益律师、媒体记者及法律工作者提供一份真实、权威、可直接引用的“维权弹药库”。**


## 🚀 如何使用本项目？（欢迎“白嫖”）

本项目完全开源，**不需要任何授权，欢迎任何人自由下载、引用、截图或转发**。
*   **如果你是被坑的消费者**：你可以直接将这些判例和法规附在你的12315投诉单或起诉状中，作为你主张“条款无效”的法律依据。
*   **如果你是媒体记者**：你可以直接从库中提取案号，采信作为报道背景。
*   **如果你是律师**：欢迎将这些裁判规则作为法庭辩论的参考。
